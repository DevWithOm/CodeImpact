# CodeImpact

AI-powered codebase intelligence platform that helps developers identify:
- Potentially unused functions and exports.
- Unused files and dependencies.
- Duplicate code blocks.
- Dependency graphs, circular dependencies, and technical debt risk.

## Architecture

- **`frontend/`**: React + Vite UI (BHOOMI_1)
- **`backend/`**: FastAPI Backend & Orchestration (TANUJA_4), Static Code Analysis (OM_2), Dependency Impact Engine (SAMAR_3)
- **`tooling/`**: Pinned Node.js static analysis tools (Knip, jscpd, Madge)
- **`fixtures/`**: Test repositories and expected findings
- **`docs/`**: Product, technical, design specs, and implementation plans
